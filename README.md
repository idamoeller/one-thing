# One Thing

A minimalist focus app — dumps my whole to-do list, then shows me one task at a time
so I'm not overwhelmed. Tag tasks by priority, urgency, energy, and time; pick by
filter, by hand, or dealer's choice; then a big single-task screen with an optional timer.

Runs entirely in the browser. Tasks are saved locally on the device.

Live at: https://imoeller.github.io/one-thing/
